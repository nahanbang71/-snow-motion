# Boom Boom Drop 네온 타이포 클립

## 캡컷에서 쓰는 법
1. 클립을 타임라인의 영상 트랙에 올립니다. 곡 오디오는 맨 아래에 둡니다.
2. 클립을 선택하고 오른쪽 패널 `비디오 > 기본`에서 `혼합`을 `스크린`(화면)으로 바꿉니다. 검은 배경이 사라지고 네온만 남습니다.
3. 클립 **시작**을 가사가 시작하는 박자에 맞춥니다. 클립 안의 깜빡임과 펄스가 곡 템포(143.5 BPM)에 맞춰 있어서, 시작을 박자에 맞추면 깜빡임도 박자에 맞습니다.
4. 랩이 빠르면 클립 `속도`를 올려서(1.3x~2x) 타이핑 속도를 맞춥니다. 다음 줄이 시작될 때 끝을 자르면 됩니다.
5. 배경 그라데이션은 별도 영상을 아래 트랙에 깔면 됩니다.
