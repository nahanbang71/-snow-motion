# 한국 전통문양 (Korean traditional patterns)

네온/레이저 라인 아트 SVG 모음. 글자(이름) 없이 문양만, 화면 중앙의 점에서 시작해 커지면서 화면 밖으로 나가는 8초 애니메이션 (1920×1080).

- `intro.svg` / `intro.mp4` : 모든 문양이 화면을 가득 채우는 인트로
- `index.html` : 전체 갤러리
- `_preview/` : 문양별 정지 이미지(미리보기)
- `_source/` : 원본(참고용) 이미지
- 번호 폴더 : 분류별 SVG
